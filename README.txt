NAGI hair & life — 架空の美容室 サンプルサイト

【開き方】
ZIPファイルを展開（解凍）し、salon-nagi フォルダー内の index.html をブラウザーで開いてください。
インストールやビルドは不要です。インターネット接続がなくても表示できます。
推奨：最新版の Chrome / Edge / Safari / Firefox。

【ファイル】
index.html：文章・ページ構成
style.css：色・レイアウト・スマートフォン対応
script.js：スマートフォン用メニュー・予約案内ダイアログ
assets/：サロンのオリジナルSVGイラスト・アイコン

【編集】
店名、文章、料金、住所は index.html を編集してください。
色は style.css 冒頭の :root にまとめています。
画像を差し替える際は、index.html の img の src と alt を更新してください。
フォルダー構成を保ったまま、静的サイト対応のサーバーへアップロードできます。

【デモについて】
店舗、住所、駅、料金、営業時間はすべて架空の設定です。
予約ボタンは案内ダイアログを表示するデモです。送信・予約受付機能はありません。
実際に公開する際は、店舗情報と予約先を置き換え、デモ表示を調整してください。
外部ライブラリ、外部フォント、外部画像への依存はありません。
